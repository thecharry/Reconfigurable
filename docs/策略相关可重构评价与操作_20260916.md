# 策略相关可重构判断、评价和使用说明

本次更新按“输入条件”选择的同步分时、异步分时、联合优化复用计算评价。硬件理论能力保留作对照，评价不再使用综合分数的正负判断可重构。优化搜索队列和严格布局搜索约束没有修改。

## 一、现在的三个口径

1. **硬件纯轴理论能力**：在健康推力器独立占空比0≤u≤1的条件下，分别最大化六轴正负输出，同时约束其他五个分量为零。它不含组绑定、最小脉宽和调度限制，是理想能力对照。线性规划未可靠完成时明确报错，不再把求解失败记成零能力。
2. **当前策略已验证能力**：将不同幅值交给真实调用器，重新积分最终喷气时序，核对故障台、周期范围、最小脉宽、重叠时间、返回脉宽与时序的一致性，以及实际输出。表中记录已经验证成功的最大端点，属于数值可行见证下界，不宣称全局最优或端点之间连续可达。固定组的外推端点也必须重新调用和验证。
3. **统一参考指令**：各布局使用相同的12条单轴指令及36条姿轨组合指令。默认单轴幅值为额定推力的0.2倍，力矩幅值为额定推力×2 m的0.2倍；额定推力10 N时分别为2 N和4 N·m。记录实际时序的跟踪误差与硬件约束，通过率不是闭环成功率。

策略方向和参考指令的归一化相对误差门槛为10⁻⁵；尺度统一采用额定推力和额定推力×2 m。默认参考长度可通过参数`evaluation_reference_length`设置，参考比例可通过`evaluation_reference_fraction`设置；界面当前使用2 m、0.2。瞬时纯控制额外检查每一喷气分段的非目标分量归一化绝对值≤10⁻⁹。

“等脉宽2/4/6方向”另外枚举全部允许组，是固定的结构基准：非目标容差10⁻⁹、目标门槛10⁻⁵−10⁻⁹。它不等于当前策略实际选出的组，也不是最小脉宽和多轴调度的完整验收。

**12向分别可用，不等于任意幅值、任意多轴指令都能执行。** 最小脉宽导致小指令空隙；有限次验证失败也不构成该策略所有可能调用均不可行的证明。因此界面使用“未证实”，不把它报告为全局无解。

## 二、代码和界面的变化

- `Reconfig_eval.m`内的策略评价局部函数统一计算，输出`Z.Invocation`策略结果及`Z.Hardware`硬件对照，并缓存相同输入，避免界面多个子页重复计算。缓存包含策略、脉宽、周期、矩阵和评价条件。
- 原输出名`Jc1`/`Z.Jc`现在表示策略最弱纯轴能力，分别为力和力矩；`Jc2`为各方向已验证能力的最大值。`Jc6`是统一尺度下的最弱方向值，**不再是旧定义的六维内切球半径**，旧、新数值不能直接比较。
- `Reconfig_eval.m`内的时序积分局部函数从最终时序计算周期平均作用、瞬时干扰峰值、最大累计干扰冲量、周期末残留，以及干扰的时间一阶矩。
- `RCPlotter.m`内的`reconfigStatus`方法统一图表与脚本的判据；向量夹角、跟踪评分和耗量评分不再决定可重构性。单条指令拟合成功也不再让联合调用器报告“系统严格可重构”。
- “可重构判断”显示策略能力、硬件能力、方向通过数和参考指令通过率。“策略能力与干扰”表提供详细对照；“控制能力包络”恢复原三维力/力矩包络：硬件投影为浅色实线面，策略已验证样本凸包为较深虚线面，并显示实际验证点。样本凸包仅帮助比较形状，其内部不保证可达；当前采样包括正负单轴端点和参考指令，并非完整策略边界。
- “硬件向量区分度”保留归一化后的向量夹角代理；它不是考虑传感器、激励和诊断算法后的可诊断性证明。
- 未完成同一参考任务的耗量不参与节能优势评分；旧的不同量纲直接相加的汇总分数停用。详细结构保留在导出的MAT结果`PolicyEvaluation`中。
- 切换调用策略会清空旧判断与评价，要求重新计算。
- 修正备用候选的单位错误：脉宽秒数现在与最小脉宽秒数比较，而非与占空比比较。这可能使原本被错误剔除的备用候选重新可用。

此更新增加了MATLAB Optimization Toolbox的`linprog`依赖。当前环境已经实际运行验证。相关求解器返回状态采用[MathWorks官方接口](https://www.mathworks.com/help/optim/ug/linprog.html)。

## 三、联合优化复用是否等于理论硬件能力

一般不相等。理想硬件作用集合为

\[
\mathcal W_H=\{Bu:\;0\le u_i\le1,\;u_f=0\}.
\]

若要求最小脉宽，单周期占空比必须满足

\[
u_i\in\{0\}\cup[t_{\min}/T,1].
\]

这只是硬件连续占空比集合的子集；进一步加入绑定、台数、排程、瞬时干扰限制时，还可能缩小。若取消这些额外限制，使用相同物理矩阵和故障集合，并且求解器确实找到所有需要的最优分配，联合分配的理论可达集合才与上述硬件集合相同。

当前`Joint_Optimization`采用有界最小二乘、按最小脉宽选取激活集合、再求解，并使用有限迭代和正则项。它没有全局枚举最小脉宽的全部离散模式，因此存在“硬件有能力但当前算法没分配成功”的可能。当前联合模式也**不强制2/4/6台绑定，不保证瞬时纯控制**；不能直接把其成功等同于严格布局优化验收。

新界面区分硬件上限与当前程序已验证能力。两者相同的某个轴向端点，不表示整个可达集合或小幅值任务也相同。

## 2026-09-17：连续分配控制能力（以本节为准）

按用户明确的定义，“理论控制能力”和“实际控制能力”均采用连续占空比，区别只在分配限制。最小脉宽、周期时间和喷气调度不进入这两类能力图。

- 理论控制能力：健康推力器各自独立取0至1占空比。沿用原六维集合的三维力投影和力矩投影。
- 实际控制能力：读取当前主/备调用组，保留每组各成员的固定相对占空比。将比例归一化至最大成员为1，则一个组的整个连续集合为`{alpha * B_group * ratio : 0 <= alpha <= 1}`（这里B_group含最大推力）。12个带符号方向的集合共用原点取并集，不求跨方向凸包，不额外添加不同轴向组相加的输出。
- 对于当前纯轴向组，这个集合通常退化为线段。图中如实显示线段；同向重叠只保留最远端，不连接不同方向的端点、不填充空隙。原点只是所有组零占空比的共同输出，不再有“已验证点”标记。
- 固定主/备组使用调用库的首选组。故障备用若依赖在线冲量裕度评分而没有固定首选组，连续图取现有备用候选库中各固定比例组的并集；不加在线时序筛选。它不是所有数学上可能组选的穷尽搜索。
- 同步和异步使用相同组选及比例时，这个视图相同。联合优化允许健康推力器独立连续分配时，两类能力空间重合；这是分配域的性质，不保证现有数值求解器对每条指令都求解成功。
- 最小脉宽、调度、参考指令通过率和干扰继续在“时序验证”相关列计算，不能与连续能力混为一谈。原综合评价的Jc仍是时序验证能力，归一化图已明确标注。明细表新增“实际单轴力/力矩”连续指标，并列“理论单轴力/力矩”；这些数值是各正负单轴能力的最小值，不是投影包络体积或内切球。

实现位置：`Thruster_invocation.m`直接提供连续分配组选；`Reconfig_eval.m`内的`Continuous_Control_Capability`计算集合数据；`RCPlotter.m`绘制集合并集；`source/RCDesignerPrototype.m`显示新名称和明细。没有新增`.m`文件，旧样本凸包实现注释保留。

## 2026-09-17：多轴联动联合包络（最新口径）

用户补充：不同轴向需要同时连续调节。因此实际控制能力不能只取各方向线段的并集，而应将各轴组输出相加。设R的各列为所选调用组的推力器占空比比例，a为各组调用强度，M为包含最大推力的控制矩阵，则联合空间满足：

`w = M*R*a, a >= 0, R*a <= 1`。

最后一个条件逐台限制总占空比，不含周期时间参数，也不属于最小脉宽或调度约束。它防止多个组共享同一台推力器时重复计算硬件能力。未共享资源的调用组可同时达到上限；共享资源则切去部分角点。

绘图步骤：
1. 读取故障工况下现有策略的主/备组选及固定比例。
2. 每个目标轴选择一套允许的正向或负向组，不同轴联动；同轴互斥备用组选分成不同分区。
3. 对每个三维投影分区，枚举占空比约束的活跃组合，求得多面体顶点。当前组是纯轴向组，未显示的另三个轴取零不会缩小投影范围。
4. 固定的每个正负方向仅有一组时，整体集合可证明为凸，合并为完整包络。同轴正负调用的抵消部分可以移除并释放资源，因此不额外扩大输出范围。
5. 存在互斥备用候选时，分别绘制各联合多面体的并集，不跨这些分区取凸包。图上可能保留分区边界；不会把分区之间的空隙填成可达区域。
6. 实际集合满三维时显示实体包络，退化时显示二维面、一维线或原点。理论控制能力沿用独立连续分配的包络。

能力图仍不包含最小脉宽和调度时间。同步/异步使用相同组选时仍具有相同连续空间；联合独立分配仍与理论空间重合。原时序评价另列保留。新增逻辑仍全部位于原`Reconfig_eval.m`、`RCPlotter.m`和界面文件；单方向绘图代码已注释保留。

## 2026-09-18：姿轨干扰页

“策略能力与干扰”页更名为“姿轨干扰”。每个布局、故障工况固定显示同步分时复用、异步分时复用、联合优化复用三行，不受当前下拉框只选一种策略的限制；其他评价页仍按下拉框所选策略计算。

仅显示布局/故障/策略、干扰力峰值、干扰力矩峰值、两类超限判断、干扰相对反向控制能力的最不利比值、周期末残留干扰冲量和角冲量。原综合评分、方向覆盖、参考通过率和耗量不在本表显示；原明细方法完整保留为`RCPlotter.legacyPolicyComparisonData`。

所有策略使用同一套52条指令：26个方向的纯力、26个方向的纯力矩，覆盖正负单轴、双轴及三轴联动。各类指令的矢量模长一致，默认分别为单台最大推力的20%及统一力矩尺度的20%。这避免仅测单轴时遗漏同步/异步的组间联动差异。纯力指令产生的力矩为姿态干扰，纯力矩指令产生的力为轨道干扰；不将本类别轴间误差混入本页姿轨干扰。峰值来自真实时序逐段的矢量模长，不是不同时间的三个分量峰值拼接。

判断逐时段取干扰的反方向，在该策略的连续纯力/纯力矩能力集合中求径向上限，记录“干扰/反向能力”的最大比值。大于100%为超限；Inf表示该反方向无非零能力。不同时间的峰值及最大比值未必出现在同一时段，不能简单用两列相除推导能力。

比较采用完整连续控制能力，未扣除正在执行任务的占用，不表示即时能补偿，也不表示闭环稳定。对于指令未实现、时序不合法或求解未可靠完成的情况，显示待复核/能力求解未完成，避免把未执行指令形成的零干扰判为正常通过。残留冲量单列显示，不用峰值替代周期末累积影响。

## 2026-09-18：撤下姿轨干扰结构评价模块

评估结论：周期末干扰角冲量原算法为各时段机体系干扰力矩乘时长后的向量和，再取模长，并对测试指令集取最大值，即`max_command norm(sum_segment(M_cross * dt))`。它依赖具体指令、喷气起止时刻和周期，不能当作仅由布局决定的结构指标，也不等于对力矩模长直接积分。

结构分析可证明某些固定比例同步组的瞬时配平，也可通过放宽约束得到异步/联合调用的潜在干扰上界。但此类上界通常不能反映真实时序中是否达到，不能可靠区分策略实际优劣；更不能据此判断补偿后的残留或闭环稳定性。故不再为该页引入任意参考指令，也不以宽松上界替代实际干扰结果。
