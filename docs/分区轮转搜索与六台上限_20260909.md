# 分区轮转搜索与六台上限

2026-09-10起默认入口已改为《组选相容性分解实现_20260910.md》；本文的单区域轮转仍可通过`solver='fair'`选择。

## 本轮确认的问题

两小时记录 `Optim_search_20260907_230425_623_*.txt` 显示：1000初值中实际启动307个，本地阶段约60秒，随后约7141秒进入联合阶段；原来的恢复文件只恢复几何候选，没有恢复待处理区域。因而增加初值数量不代表完整扫描了更多拓扑。

历史152/156候选确实有几何数据。导入失败是因为搜索失败时顶层 `B_opt/r_opt` 故意为空，而导入器遇到这两个字段就直接读取，没有继续读取 `saved.best_coverage_x`。此外，原下拉框更新逻辑优先保留“原布局”，没有选中新导入项。这两处现在均已修复，导入后选中“待验证候选”，不会标为可行优化结果。

## 当前硬约束

- 保持两安装面、12台等推力推力器、三个严格中心对称模块。
- 每个轴向的一个严格同步控制组只允许2、4、6台；不再考虑8台及以上。
- 标况与每台单故障后的12个正负轴全部满足要求，共156项。
- 故障推力器不能入组；允许跨模块选组，不把固定“搭档”一并排除。
- 每组所有推力器同步等时喷气，组的非目标五维分量为零。
- 不优化控制能力大小。`1e-5`仅作为归一化非零能力判据，纯组容差保持`1e-9`。

完整偶数组列表从2047组减少为

\[
\binom{12}{2}+\binom{12}{4}+\binom{12}{6}=1485.
\]

实际调用器的严格组搜索上限也同步改为6台。该上限是“一个轴向的一个组”，不是多轴联合指令下同时参与控制的整星总台数上限。

## 搜索步骤

这里没有先显式列出所有完整拓扑再逐个求解。单故障后已有 `C(11,2)+C(11,4)+C(11,6)=847` 个健康组选项；36个代表需求的原始选组组合上界为 `847^36`，其中大部分尚待方程排除。当前用二进制变量隐式选组，用几何区域轮转管理时间，不能把“处理一个分区”称为“遍历一个拓扑”。

1. 用当前约束重新核验历史候选和初值。默认路径只扫描，不对每个初值连续执行局部最小二乘，因此不会先在某个初值上反复配平。
2. 将十二个几何变量的完整边界作为首个待处理区域。每个区域内同时求解几何和36个代表需求的二进制选组变量；利用构型对称性，故障1、5、9上的36项与全部单故障需求等价。最终仍独立检查156项。
3. 每个区域默认最多求解15秒。这里没有固定某个推力器拓扑，也不使用固定方向库作为默认搜索空间。
4. 交替使用两种调度：一次取最浅、最早的区域；一次优先取接近已知候选的区域。后者是距离启发式，不是“可行概率”。广度轮转保证其他待处理区域不会永久饿死。
5. 求解器数值判定不可行的区域才排除；超时不是不可行。未解决区域按相对宽度最大的变量一分为二，两个子区均保留，分割点也包含在两侧中。
6. 候选解回到MATLAB后，独立枚举全部健康2/4/6台组，检查156项、安装边界和实际调用器。只有全部通过才填入 `B_opt/r_opt`。候选未通过时，其所在区域仍保留在细分后的队列中。
7. 每个区域结束后保存JSON检查点，正常结束后把整个待处理队列存入MAT记录；处理历史保留最近256条和累计计数，待处理队列不截断。续跑不是从根区域重来。物理边界、容差、非零判据或组台数上限改变时，旧队列失效，重新开始。

保存的是外层分区队列，不是SCIP内部完整分支树。不同分区中可能再次检查同一组选项，这是该拓扑在不同几何范围上的检验；不能宣称所有内部求解工作都被恢复或从不重复。

## 使用方式

软件保留原来的初值数量和总搜索时限设置。默认求解方式为 `fair`，无需更换调用策略选项。建议先用16个初值、120秒检查队列处理与恢复是否正常，再延长搜索；不建议继续用1000初值作为加速手段。

同一软件会话再次点击优化，会恢复上一轮队列。重新打开软件后，可导入新的 `Optim_search_*.mat` 查看候选，再点击优化恢复该记录。旧版记录没有队列，只能作为几何初值恢复。

直接调用时可设置：

```matlab
cfg = struct('solver','fair','start_count',16,'max_time',7200,'node_time',15);
r = Optim_Algorithm(Get_params(),cfg);
cfg.resume_file = r.output_file;
r2 = Optim_Algorithm(Get_params(),cfg);
```

异常中断时也可把 `resume_file` 指向诊断中的 `Optim_queue_*.json`。检查点用于恢复搜索，MAT记录用于导入软件查看几何。

## 能保证和不能保证的事

该实现保证调度不固定在同一个未解决区域、未证明不可行的区域不因超时丢弃、续跑保存前沿，以及只有完整复核通过才返回可行布局。它是数值分区可行性搜索，不是“所有拓扑已经枚举完”的证明，也不是数学精确的全局可判定算法。

不能承诺“只要时间足够就一定找到布局”：首先全约束解可能不存在，其次严格等式可行集可能没有体积，数值分支求解没有普遍的有限时间成功保证。限制到6台后必须重新核验，旧152/156也不能直接继承。要作严格存在性/不存在性结论，需要另行对多项式系统实施可靠的区间或符号证明，当前程序不声称已经实现此证明。
