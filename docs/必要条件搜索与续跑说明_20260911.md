# 必要条件搜索与续跑说明

本版将“完整组选必要条件”与“安装几何与布局”分成两个阶段。完整必要条件通过仍不是物理可行布局；仅力配平78项通过也不是完整必要条件通过。

## 如何操作

1. 关闭正在运行的旧软件，在项目目录运行 `Run_RCDesigner`。如果仍显示旧界面，完整退出并重新打开 MATLAB。
2. 进入“优化设计”，确认安装范围和间距、夹角等约束。搜索阶段选择“完整组选必要条件”。
3. 先使用默认 **600秒/轮**，点击“查找必要条件”或“继续查找”。运行期间不用再点，软件在发现完整见证、达到本轮时限或需要证明复核时自动停止。
4. 若显示“仅力配平已通过（78项）”或“本轮未判定”，保持600秒再次点击即可续跑。也可设置1200—1800秒以减少初始化开销；延长时间不保证一定找到结果。不要把多次超时解释为无解。
5. 显示 **“完整组选必要条件已找到｜156/156项精确复核通过”** 时，这一阶段的按钮会禁用，无需再点，也不必等进度条达到100%。切换“安装几何与布局”，点击“搜索安装布局”。这一阶段继续检查单位方向、位置与力矩的关系、安装范围、间距、夹角及完整故障调用。
6. 只有显示 **“首个可行布局已生成｜156项及调用器复核通过”**，才取得可用物理布局。

重新打开软件会自动载入最近记录，点击后先重新复核证据再续跑。也可以点击“载入搜索记录”，选择某次目录里的 `diagnosis.json` 或根目录的 `Optim_diagnosis_latest.json`。载入文件声称成功时，仍需要一次独立复核，复核完成后才开放几何阶段。

## 状态如何判断

| 软件显示 | 是否继续点击本阶段 | 含义 |
|---|---|---|
| 仅力配平已通过（78项） | 可以 | 力矩配平尚未完成，不是完整必要条件 |
| 本轮未判定／记录已保存 | 可以 | 未完成分支还在；超时没有被当作无解 |
| 完整组选必要条件已找到，156/156项精确复核通过 | 不需要，按钮禁用 | 完整必要条件已通过，可以切换安装几何阶段 |
| 需要复核已保存的证明材料 | 不需要，按钮禁用 | 当前没有可继续搜索的分支，剩余证明需独立核验；不是已认证无解 |
| 当前约束下已认证无解 | 不需要，按钮禁用 | 已验证的必要条件矛盾足以否定当前约束下的物理问题 |
| 首个可行布局已生成，156项及调用器复核通过 | 不需要 | 已生成物理布局 |

运行中有部分“待复核”分支、但仍有“待搜索”分支时，其余分支仍可搜索。只有全部可搜索分支耗尽而证明尚未复核时，才进入需要处理证明的停止状态。

## 排除、续跑和进度条

- 对历史组选冲突逐条使用有理数复核，合格证据去重后加入完整力／力矩搜索；普通数值不可行、超时和 `unknown` 不生成永久排除。
- 完整必要条件的外部分支被保存为一个互不重叠、覆盖原始组选域的有限分区。未知分支拆成两个子分支并全部保留；意外中断时当前分支在磁盘上仍是待处理状态。
- 初始筛选先对一个代表需求做严格的目标能力上界检查。不能达到目标门槛的整片组选域会带证据关闭；只需展开最多11个选择位，不穷举全部36项组合。
- 进度条等于“已认证排除的组合数 / 原始组合总数”。所有已关闭分支的证据、相互独立性和完整覆盖都会在续跑时重新检查。用整数和分数计数，显示时才转成百分比。
- 冲突条数不直接换算百分比：不同冲突可能排除重叠范围。进度条只计已经划成互斥区域并带证据关闭的部分，因此是已排除范围的保守计数。
- **每轮不一定新增排除。** 可能只是拆分未完成分支，或者留下待复核的证明。百分比长时间不动仍可能积累有效搜索记录。
- **百分比不是时间进度、成功概率或物理布局完成度。** 容易排除的大块区域可能迅速消失，剩余小比例仍然极难。找到见证时不需要100%；只有排除整个域才需要全覆盖证明。

保存的是外部分支和可复核证据，不是Z3内部的完整搜索树。单轮运行内共享同一个求解器实例；跨轮重新建立求解器并载入分支与冲突。因此长一点的单轮通常能减少启动开销，但既不能保证比同等总时间的多轮更快，也不能保证找到解。

## 搜索空间有限吗

对于当前12台、单故障、健康2/4/6台组选模型，一个代表故障下可选组数为

\[
\binom{11}{2}+\binom{11}{4}+\binom{11}{6}=847.
\]

利用三个模块的对称性，有3个代表故障，各12个有向力／力矩需求，共36个组选变量。因此原始带标签组合域是

\[
847^{36}\approx2.534\times10^{105}.
\]

这是有限数量，也是进度计数的分母；大量组合随后会被必要条件排除，并不意味着需要逐个枚举。外部分支最多固定396个健康成员选择位，未知分支的拆分深度有限。

**有限组合空间不等于当前软件保证在有限轮次或可接受时间内完成。** 对固定组选还要判断连续系数约束；固定成员全部确定后，求解器若仍因时限返回未知，就保留重试。一般Z3无解证明目前没有接入独立通用证明检查器，可能转入待复核。当前实现因此不承诺“再点若干次必然有结论”。物理安装阶段还存在额外的连续非线性约束。

## 文件与约束变更

每轮产生 `Optim_diagnosis_时间_编号/`：

- `diagnosis.json`：两层诊断、见证、队列引用及状态。
- `branch_queue.json`：分支、已核验冲突、关闭证据和累计统计。
- `report.txt`、`result.mat`：便于查看的报告及MATLAB结果。
- 若需要，保存 `.smt2` 和 `.z3proof`，供后续证明核验。
- 完整必要条件通过后，生成 `geometry_queue.json`，自动交给安装几何阶段。

`Optim_diagnosis_latest.json` 指向最近记录。**请保留整个搜索目录及其引用的旧证据目录**，不要只复制一个JSON文件或删除旧证明文件。

改变安装范围、能力门槛、容差等约束会创建新域，不混用原有进度；历史冲突如果在新门槛下再次通过独立检查，仍可以复用。只改变本轮时限不会清空队列。当前几何接续支持俯仰角位于 `[0,π/2]` 的模型；其他范围可做必要条件诊断，但不会错误地套用此几何检查点。

## 本次实际验证（2026-09-11）

已用实际应用按钮运行30秒、30秒、10秒三轮，累计求解次数依次为3、6、9；第二轮及第三轮接续未完成分支。重新打开应用和使用 `Run_RCDesigner` 启动均正常，MLAPP内代码与源码一致。

最终记录中，有1068条复核后去重的冲突、170个已认证关闭分支、167个待搜索分支、0个待证明复核分支。已认证排除比例为 `345/847 ≈ 40.731995%`，主要来自初始目标能力上界筛选；后两轮拆分未知分支而没有增加排除比例。这不是搜索耗时完成了40.73%。队列证据、互斥分区和覆盖总量已经独立重算。

**真实结论仍是：力配平78项通过；完整力／力矩必要条件未判定；未取得物理可行布局，未证明默认原问题无解。** 最近记录已设为自动续跑入口，可以直接继续。

验证包括已有43项Python测试、新增11项分支队列测试、18项MATLAB优化器测试和4项界面状态测试。界面的成功／停止状态使用明确标注的模拟记录验证；真实搜索记录没有被改写成成功结果。新增测试还涵盖有证据的完整域排除、真实Z3分支无解公式重放、未知分支保留、意外中断、证明损坏拒绝及跨轮累积。
