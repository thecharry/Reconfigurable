# 729类零/自由模式搜索

2026-09-10起默认入口已改为《组选相容性分解实现_20260910.md》。本文保留旧方法说明；仍可显式选择 `solver='patterns'`。

## 计数与物理含义

变量仍为三个模块的 `[y,z,alpha,beta]`，共12个。对每个模块：位置对的模式为`10、01、11`，角度对也为`10、01、11`，因此共有`3*3=9`种模块模式，三个带编号模块共`9^3=729`种。

这里`0`表示固定为0，`1`表示在原安装边界内自由优化。自由变量允许最后取0。这样各类是有重叠的闭集，不会因人为的“非零下限”漏掉接近零或恰好位于边界的解。不能将它称为729个互斥、完整的推力器选组拓扑。

|按掩码计数的自由变量数|类数|
|---|---:|
|6|64|
|7|192|
|8|240|
|9|160|
|10|60|
|11|12|
|12|1|

另有两点物理区别：

- 当`beta=0`时，方向沿X轴，`alpha`不再改变实际推力方向，所以掩码中的自由变量数不一定等于有效物理自由度。
- `alpha=0`本身是合法方向角，并非“方向不存在”；`alpha=pi`也可令某个方向分量为0。方向分量为`cos(beta)、sin(beta)cos(alpha)、sin(beta)sin(alpha)`，因此角度零值模式不等于力/力矩矩阵的零值模式。

用户提出的729类在数值实现中采用闭包：排除的是两个位置位或两个角度位同时标为“固定0”的掩码，而不是额外禁止自由变量最终同时落到0。若需要禁止某些重合安装位置，应由实际安装距离硬约束表达。所有原有安装约束保持有效。

## 算法

默认`solver='patterns'`。算法为**零/自由模式枚举 + 混合整数非线性可行性求解 + 分轮分区细化**，不采用遗传算法，不最大化控制能力。

1. 一次生成完整729类清单，并按自由变量数由少到多排序。固定0与用户边界冲突的类直接记为`bounds_excluded`，不会消失在清单里。
2. 对每一类，把掩码为0的变量上下界都设为0，其他变量沿用安装面和角度边界。固定变量可由求解器预处理消去。逐类求解时不施加模块间的额外编号排序，以免误排除某个带编号模式。
3. 类内联合求解几何变量和各轴的组选变量，推力器允许跨轴复用。没有要求某个轴只能使用预先指定的一对推力器。
4. 初轮每类默认最多5秒；**所有兼容类先各处理一次，才处理任何细分区域**。超时标为`unresolved`，不标为无解。
5. 未解决区域沿相对宽度最大的自由变量二分，两侧全部保留。随后逐层遍历，并在同层中按每类已调用次数轮转。每深入一层，单区域预算翻倍，最高为初始预算的16倍。只有数值判定不可行的区域才排除。
6. 收到候选后，由MATLAB独立检查安装条件、156项健康偶数纯控制组以及现有调用器。模式候选不再交给全域局部精修，以免把该类固定为0的变量改成非零。
7. 任一布局完整通过检查就返回；否则保存整个未解决队列和729类状态，下次继续。旧分区方法的队列与本方法不兼容，会明确重新建立模式队列，历史几何初值仍可利用。

每个组选向量`b`独立满足：

\[
A(x)b=c\,s e_k,\qquad c\ge 10^{-5},\quad b_i\in\{0,1\},\quad \sum_i b_i\in\{2,4,6\},\quad b_f=0.
\]

`A(x)`是按最大推力和安装面距离归一化的六维效率矩阵；`k`为目标轴；`s`为正负方向；`e_k`仅第k个分量为1；`c`为该组归一化目标轴能力；`f`为故障编号。非目标五行必须配平为零，最终独立容差为`1e-9`。目标函数是常数0，只寻找可行性。未引入跨轴的`sum(b_i)<=1`限制。

## 记录与使用

- 软件现在显示“已初筛多少/729类、当前类编号、自由变量数、最高覆盖”。初值数量只影响初始几何候选，不控制729类是否枚举。
- 每次运行都输出全部729行的`.patterns.csv`：编号、分模块自由掩码、自由变量数、求解调用次数、状态、累计用时。
- `pending`是未初筛；`bounds_excluded`是固定0不符合输入边界；`unresolved`是尚未解决；`numerically_infeasible`是该类所有区域已被数值排除；`candidate_for_matlab_verification`只是待复核候选，不是可行证明。
- `.mat`和`Optim_queue_*.json`保存待处理队列。MATLAB返回值的`pattern_table_file`指向清单文件。
- `solver_evidence.free_mask`对应求解器原始模块顺序，`actual_zero_mask`记录候选中精确等于0的参数；最终布局为显示和复核可能等价重排模块，因此需要用`solver_evidence.x`对照该掩码。

```matlab
cfg = struct('solver','patterns','start_count',16,'max_time',7200,'node_time',5);
r = Optim_Algorithm(Get_params(),cfg);
cfg.resume_file = r.output_file;
r = Optim_Algorithm(Get_params(),cfg);
```

首次扫描的单区域求解预算总和上界约为`729*5=3645秒`，还存在模型建立、数据保存和候选复核开销，不能当作严格墙钟时间承诺。总时限用完就保存进度，不会把剩余类丢掉。

## 完备性边界

本方法完整列出了上述729个零/自由掩码，且全自由类包含原十二变量空间；没有因为固定方向库而遗漏该空间。它**不保证在有限时间内找到严格等式系统的可行解，也不把遍历一遍729类等同于证明全空间无解**。同一掩码内部仍有连续取值和大量组选组合。若全约束本身无解，增加计算时间也不会产生一个正确的布局。

## 联调结果

采用每类初轮0.2秒的短预算验证调度流程：第一轮60秒检查415类，恢复后再运行90秒，累计检查729类并处理798个区域。729类均有求解调用，216类在当前数值模型下排除，513类仍未解决。仍未找到156/156布局，不能把短预算初筛当作充分求解。

完整状态表在`recovery/zero_free_729_patterns.csv`，可续跑记录在`recovery/zero_free_729_search.mat`。正式运行仍默认每类5秒，并逐层增加预算。17项Python回归测试验证了计数、固定零边界、首轮公平遍历和原有选组约束。
