# 分层精确可行性诊断

2026-09-10。新增独立入口 `Diagnose_Layout_Feasibility.m` 和后端 `strict_layout_diagnosis.py`。也可通过 `Optim_Algorithm` 的 `solver='diagnostic'` 使用。原几何优化入口的默认方法仍为 `decomposed`。

**本次实际结果：力配平必要条件已找到解并通过全部78项精确复核；完整力／力矩组选必要条件在限时内未判定。没有取得156项完整布局，也没有证明默认原问题无解。**

## 两层模型的边界

|层|共享实系数|代表需求|独立验收|移除的条件|
|---|---:|---:|---:|---|
|force：力配平|9个，三个模块各c、p、q|18项|标况及12个单故障，共78项|力矩条件、单位方向范数、位置与方向的非线性关系、一般角度扇区及安装间距/夹角|
|wrench：力和力矩配平|18个，三个模块各c、p、q、h、g、k|36项|标况及12个单故障，共156项|单位方向范数、位置与方向的非线性关系、一般角度扇区及安装间距/夹角|

两层都保留12台推力器、三个模块的完整符号对称关系、失效台禁止入组、2/4/6台同步等时组，以及 `ε=1e-9` 的非目标最大分量容差和 `ρ−ε=9.999e-6` 的目标能力门槛。力配平层的“纯力”只在三个力分量中判定，不要求消除力矩。

方向系数与力矩系数使用有理数外包络。例如 `|p|,|q|≤1`、`|h|≤(max|y|+max|z|)/a`、`|g|≤1+max|z|/a`、`|k|≤1+max|y|/a`。默认朝内半球保留 `c≥0`；输入超出该半球时放宽为 `−1≤c≤1`。仅在输入明确固定 `α=0` 或 `β=0` 时应用相应恒等式，不把接近零的角度取整为零。

**每个物理可行解一定映射为这两层的解，反向不成立。** 因此，可靠地证明任一层无解可以否定原问题；找到两层的系数解仍须进行安装几何求解。

## 精确求解与复核

Z3模型属于布尔逻辑与线性实数算术 `QF_LRA`。用 `if selected then coefficient else 0` 表示成员选择，避免引入两个实变量相乘。门槛和边界按接口输入的十进制值转成有理数。所有系数统一除以 `ρ−ε`，使目标门槛变为1；非目标界变为 `ε/(ρ−ε)`。这个缩放不改变可行性。

Z3的数学实数、有理常数和线性实数算术支持见[官方算术说明](https://microsoft.github.io/z3guide/docs/theories/Arithmetic/)。这是本项目新增的必要条件模型，不是文献已经验证过的完整卫星布局算法。

数值对照使用SCIP，对同一组必要条件、相同边界和相同缩放建模。其二进制与连续系数乘积用线性包络精确表达二进制选择；浮点计算仍有舍入误差。本机安装未暴露精确模式，因此不把其 `infeasible` 当作证明。SCIP官方的精确模式适用于受支持的混合整数线性模型，见[官方说明](https://www.scipopt.org/doc-10.0.0/html/EXACT.php)。

返回SAT后，独立检查器不调用Z3或SCIP，仅用Python标准库的有理数运算完成：

1. 核对约束签名、系数范围、成员数量和失效台排除。
2. 从组成员重新计算完整整数符号系数与每个方向的配平量。
3. 枚举所有1485个2/4/6台组，对13种故障条件全部检查，输出具体健康组选、目标能力和非目标最大分量。

SCIP若返回候选，剩余预算允许时固定其组选，再用Z3解一次有理线性问题并复核。数值候选本身不会直接升级为“已验证相容组选”。

## 结果状态

|返回状态|含义|
|---|---|
|`necessary_conditions_sat`|完整力／力矩层已有独立复核的系数和组选见证；物理布局仍未验证|
|`diagnostic_unsat_verified`|发现并独立核验了整行系数恒为零的矛盾；证明仅针对记录的输入边界和门槛|
|`diagnostic_unsat_reported`|Z3以精确算术报告无解，保留公式和Z3证明对象；尚未通过独立的通用证明检查器|
|`diagnostic_unknown`|预算内未完成两层判定；某一层可能已经通过，应查看各层状态|
|`diagnostic_solver_disagreement`|不同结果出现矛盾，保留证据，暂停结论|

单层的 `sat_verified` 表示该层见证已经独立复算。超时、资源限额、求解器缺失和普通数值不可行都不会设置 `original_problem_infeasibility_verified=true`。

**一般UNSAT证明的独立检查仍是限制。** 当前可独立认证的是恒等式零行证据，以及所有SAT见证；保存或重新解析Z3证明并不等于拥有独立通用证明检查器。代码不会把前者冒充后者。本次默认域没有得到UNSAT结果。

## 运行和文件

在项目目录的MATLAB中运行：

```matlab
p = Get_params();
cfg = struct('max_time',240,'diagnostic_stage_time',60, ...
    'diagnostic_compare',true,'save_result',true);
d = Diagnose_Layout_Feasibility(p,cfg);
```

`diagnostic_stage_time`是每层、每个求解器的预算上限。总预算不足时为剩余层和求解器分配时间。`diagnostic_compare=false`只运行Z3。诊断入口不进行初值扫描或最小二乘；总预算也不用于最大化控制能力。

已经通过的层可以复用。例如本次第一层已通过，后续将 `cfg.resume_file` 指向保存的 `diagnosis.json`，再次调用诊断入口即可。恢复时先独立重验见证，拒绝使用篡改或不匹配的结果；仅对未解决层重新求解。约束或方法改变时重新诊断。

```matlab
cfg.resume_file = d.solver_evidence.diagnostic_report_file;
cfg.diagnostic_compare = false;
cfg.diagnostic_stage_time = 150;
cfg.max_time = 170;
d2 = Diagnose_Layout_Feasibility(p,cfg);
```

诊断恢复文件使用JSON，几何优化的MAT记录属于另一种用途。诊断文件保存的是公式、见证和状态，不是Z3内部搜索树；对未解决层使用相同配置和相同时限再次启动，可能重复之前的搜索。

输出到新的 `Optim_diagnosis_时间_标识/` 文件夹：

- `result.mat`：MATLAB返回结构，`B_opt/r_opt/x_opt`为空，`feasible=false`。
- `report.txt`：中文状态说明与各层求解记录。
- `diagnosis.json`：原始约束范围、精确见证、独立复核结果、各求解器耗时与状态。每阶段完成后更新。
- `force.smt2`、`wrench.smt2`：可由其他支持SMT-LIB的求解器重放的精确公式，记录SHA256。
- 若Z3返回UNSAT，另保存相应的 `.z3proof`，保持“报告无解”与“独立认证无解”的区分。
- 若完整力／力矩层通过，并且β范围支持现有代数几何分解，另保存 `geometry_queue.json`。

只有第二层完整见证通过才生成几何队列；第一层见证不能进入几何求解。产生队列后，可继续：

```matlab
cfg.solver = 'decomposed';
cfg.resume_file = d.geometry_checkpoint_file;
r = Optim_Algorithm(p,cfg);
```

此时应保留诊断使用的全部安装边界、能力与容差设置。输入β超出 `[0,π/2]` 时仍可做必要条件诊断，但不生成不适用于该角度域的代数分解队列。

也可使用当前Python求解环境直接运行 `strict_layout_diagnosis.py 输入.json 输出.json`，或用 `--verify diagnosis.json`重验已保存的见证和恒等式证书。未判定层会显示 `no_independently_checkable_conclusion`；报告整体尚不能被视为一个完整已认证结论。

## 本次实际试验

默认安装边界，ρ=1e-5、ε=1e-9、组上限6台；每层每个求解器最多60秒，总预算240秒，实际约205.53秒。

|层|Z3|SCIP|
|---|---|---|
|力配平|25.32秒得到SAT，独立有理数枚举通过78/78|60.00秒未判定|
|力／力矩配平|60.07秒超时，未判定|60.00秒未判定|

随后使用恢复入口重新验证并复用第一层见证，将Z3第二层单次预算延长至150秒。该次实际约150.20秒，第二层仍为unknown；第一层没有重复求解。恢复配置与结果分别为 `analysis/layered_resume_config_20260910.json`、`analysis/layered_resume_result_20260910.json`。这次重新建立了第二层搜索树，不是从此前60秒的内部节点继续。

原始配置为 `analysis/layered_240s_config_20260910.json`，结果为 `analysis/layered_240s_result_20260910.json`，公式与检查记录位于 `analysis/layered_240s_20260910/`。另有一个易于阅读的力配平系数见证 `analysis/force_constructive_witness_20260910.json`，也通过独立78项检查。

这是单次对照，不能外推Z3在所有边界和完整模型上总比SCIP快。已确认的是：力配平必要条件有解，完整力矩相容性仍需继续判定。没有生成几何队列，也没有输出新的物理可行布局。
