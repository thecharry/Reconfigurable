## 求解流程

1. 初值阶段保留历史候选，完整检查156项。新增冲突引导的组选修复：为相互矛盾的需求组选尝试替换组，生成精确冲突证据。这是有时间限制的启发式；只试附近组选不会被当作全域搜索结论。
2. 离散主问题联合选择故障1、5、9下的36个正负轴组选，每组为健康的2/4/6台。以共享的六类物理系数和线性配平必要条件形成MILP松弛。
3. 对每个得到的完整组选，检查跨需求的整数系数相容性。可证明的冲突返回主问题，排除包含相同冲突指派的所有完整组选。
4. 没有检出上述冲突的组选，固定成员后进入多项式几何求解。此时不用再联合搜索36组的成员变量。相容性检查通过只是必要条件，不表示物理上可实现。
5. 从几何候选重建真实位置、单位方向与叉积矩阵，分别由Python、MATLAB检查完整156项、安装边界及距离/夹角；最后由实际调用器复核。

默认主问题没有单位方向和力矩乘积等非线性等式，所以它是原模型的必要条件松弛。几何阶段才施加完整物理关系。可选 `strong_master_relaxation=true` 增加方向范数的线性必要条件及力矩乘积包络，当前未证明这样更快，因此不默认启用。

默认角度域中，使用

\[
c=\cos\beta,\quad p=\sin\beta\cos\alpha,\quad q=\sin\beta\sin\alpha,
\]
\[
c^2+p^2+q^2=1,\quad ah=yq-zp,\quad a(g-q)=zc,\quad a(k-p)=yc.
\]

方位角子区用扇区半平面表达；宽度超过π的子区使用两个扇区的并集，固定角度还约束射线方向，避免把反方向误算进去。空间细分后继续使用代数模型。若输入β超出 `[0,π/2]`，入口明确回退到原三角联合模型并记录 `fallback_reason`，不静默丢弃角度限制；下述新分解队列保障针对代数分解分支。

## 哪些排除有证明

对某一物理行，记三个模块的共享系数为向量v。每个组选对该行的整数系数为t。若目标组的t满足

\[
t=\sum_i\lambda_i z_i,
\]

而其他需求的组选要求同一行 `|z_i v|≤ε`，则

\[
|tv|\le\varepsilon\sum_i|\lambda_i|.
\]

当右端严格小于 `ρ−ε`，这些组选指派不可能同时满足门槛。系数关系及阈值比较使用精确有理数计算；证据记录组成员、涉及需求和有理数权重，恢复时独立重验，拒绝加载无效证据。它直接适用于当前容差模型，避免用“精确零模型无解”冒充“容差模型无解”。

例如历史152项候选的最近组选中，一条证据给出的目标能力上界为 `2ε=2e-9`，小于 `ρ−ε=9.999e-6`。该证据排除的是这些组同时被选中的组合，不排除全部位置或方向，也不把全部152项候选附近空间一并删除。

另有直接恒等式筛选：所有模块固定 `α=0` 或 `β=0` 时，Fz整行恒为零。此时输出 `proven_infeasible_for_bounds` 并附证明范围。这能识别原729类中的216个显然不可行类；默认全角度域不满足这个前提。

普通SCIP的浮点 `infeasible` 状态不作为精确非线性无解证据。本版未实现完整的有理数MILP证明日志、区间证明或CAD/NLSAT证明器，不能声称已具备整个连续问题的精确判定能力。

## 超时、保存与恢复

- 默认主问题每次获得30秒；几何子问题初始15秒，深层区域逐步增加预算，总体仍受 `max_time` 限制。
- 主问题同一次调用中超时后继续原求解实例；加入新割时才重新转换模型。跨程序恢复不保存SCIP内部完整搜索树。
- 组选一旦分派到几何阶段，先保存待解工作，再从“新组选分派”中排除。这个排除只是避免重复分派，不能算无解证明。
- 几何超时、数值不可行、候选复核失败都保留该组选。待解区域沿最长相对边分为两个闭子区，两侧均保存。可能因此重复处理实际上无解的区域；这是尚无可靠非线性排除证据的代价。
- `.mat`记录和中断检查点保存冲突证据、待解组选、几何区域及累计次数。另输出 `.conflicts.json` 便于查看证据。
- 方法或约束签名变化时重建搜索队列；旧记录中的几何候选仍可用作初值，旧模式队列不能被假装成新组选队列。改变时间预算可正常恢复。

## 统一验收

硬约束仍为健康2/4/6台同步等时组，归一化非目标最大分量 `≤1e-9`，目标有向能力 `≥1e-5−1e-9`。没有放宽台数、独立占空比或故障要求。

`Thruster_invocation`新增可选的 `strict_group_contract`。对通过严格优化的布局，调用器先筛掉能力不足或耦合超限的组，再沿用原有的组选择策略；严格组成员使用相同占空比。优化验收直接计算实际选中组的物理合成能力。软件让该验收参数随布局保留，切换布局时检查匹配，改变额定推力时更新归一化。

## 运行方式

在项目目录运行：

```matlab
p = Get_params();
cfg = struct('solver','decomposed','max_time',600, ...
    'master_time',30,'geometry_time',15,'save_result',true);
r = Optim_Algorithm(p,cfg);

% 本轮未成功时，保留其余硬约束，用记录继续：
cfg.resume_file = r.output_file;
r2 = Optim_Algorithm(p,cfg);
```

软件的“优化”入口也使用此默认方法。可在进度信息中查看已登记的待解组选、冲突数及几何检查次数；“初值数”不等于已检查拓扑数。未完成156项与调用器复核时，`B_opt`继续为空，搜索记录不会伪装为可用布局。
