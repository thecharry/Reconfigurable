# 严格主备布局优化说明

**2026-09-10起默认入口为《组选相容性分解实现_20260910.md》中的组选与几何分解，单轴组上限为6台。下面的固定方向流程和默认设置是9月7日实现的历史说明，不再是软件默认搜索流程。**

2026-09-07更新：恢复历史152/156候选；取消软件中0.1的任务能力门槛；增加固定方向的位置/组联合搜索和共享物理系数模型。数值非零判据不等于任务能力指标。只有完整156项及现有调用器复核通过，才会生成可用布局。

## 1. 本版优化的范围

本版保留用户要求的严格对称构型：两个安装面、12台等推力推力器、三个四推力器模块。同一个安装面的两台关于该面的中心对称，另一安装面上的两台由镜像关系生成。

**不再限制为两类解析构型，也不使用“51个规范化符号类”。**三个模块各自保留四个连续变量，组内选哪些推力器由配平方程决定。这里覆盖的是下述严格对称参数化及用户给定边界内的组合，不是任意非对称的12台布局。

原来的遗传算法代码保留在 `Optim_Algorithm.m` 顶部块注释中；后续旧版解析库搜索不再参与运行。

## 2. 十二个连续变量和物理矩阵

优化变量为

\[
x=[y_1,z_1,\alpha_1,\beta_1,\;y_2,z_2,\alpha_2,\beta_2,\;y_3,z_3,\alpha_3,\beta_3].
\]

- 下标 \(j=1,2,3\) 表示模块。
- \(y_j,z_j\)：该模块第一台推力器在安装面内的位置，单位 m。界面中的“位置参数a、b”分别对应这里的 \(y,z\)。
- \(\alpha_j\)：推力方向在 \(YZ\) 平面内的方位角，单位 rad。
- \(\beta_j\)：推力方向与朝内的 \(X\) 方向之间的夹角，单位 rad。
- \(a=\mathtt{x\_face}\)：安装面到原点的距离，当前软件取2 m；安装面为 \(X=\pm a\)。
- \(F_{\max}\)：单台额定推力，单位 N。

令

\[
c_j=\cos\beta_j,\quad p_j=\sin\beta_j\cos\alpha_j,\quad q_j=\sin\beta_j\sin\alpha_j.
\]

第 \(j\) 个模块的四列位置和单位推力方向为

\[
R_j=\begin{bmatrix}a&a&-a&-a\\y_j&-y_j&y_j&-y_j\\z_j&-z_j&z_j&-z_j\end{bmatrix},\quad
D_j=\begin{bmatrix}-c_j&-c_j&c_j&c_j\\p_j&-p_j&p_j&-p_j\\q_j&-q_j&q_j&-q_j\end{bmatrix}.
\]

对每台推力器 \(i\)，由位置 \(r_i\) 和单位推力方向 \(d_i\) 得到

\[
B_i(x)=\begin{bmatrix}d_i\\r_i\times d_i\end{bmatrix},\qquad
A_i(x)=\begin{bmatrix}d_i\\(r_i\times d_i)/a\end{bmatrix}.
\]

`B_opt` 储存 \(B\)，实际控制效率矩阵是 \(F_{\max}B\)。\(A\) 的六行已无量纲化，避免直接比较 N 与 N·m。

## 3. 严格偶数纯控制组方程

对故障编号 \(f\)、目标轴 \(k\)、方向 \(s\) 选择一个二进制向量 \(b^{fks}\)：

\[
b_i^{fks}\in\{0,1\},\quad b_f^{fks}=0,\quad
\sum_{i=1}^{12}b_i^{fks}=2h^{fks},\quad h^{fks}\in\{1,2,3,4,5\}.
\]

- \(b_i=1\)：该组包含第 \(i\) 台，并与该组其他成员以相同推力、相同脉宽同步喷气；\(b_i=0\)：不包含。
- \(f\in\{1,\ldots,12\}\)：失效推力器编号。只排除该故障机，不永久封锁某台健康搭档；健康成员仍可加入新的完整纯控制组。
- \(k\in\{1,\ldots,6\}\)：依次对应 \(F_x,F_y,F_z,M_x,M_y,M_z\)。
- \(s\in\{-1,+1\}\)：负向或正向；\(e_k\) 是第 \(k\) 个分量为1、其余为0的六维单位向量。
- \(h\)：组内台数的一半，只约束偶数台，不要求预先固定两两搭档。

纯控制条件为

\[
A(x)b^{fks}=s\,c_{fks}e_k,\qquad c_{fks}\ge\rho_{\min}>0.
\]

其中 \(c_{fks}\) 是该组全开时目标轴上的归一化能力，\(\rho_{\min}\) 现取 `1e-5`，只用于把有效非零量和数值零分开，不再要求达到原来的0.1。本阶段只寻找第一套满足全部要求的布局，自由方向联合模型的目标函数是常数：

\[
\min_{x,b,h} 0.
\]

代码没有单独建立变量 \(c_{fks}\)，而是直接约束非目标五行等于0、目标行满足 \(s(A b)_k\ge\rho_{\min}\)。控制能力最大化不参与本阶段。固定方向阶段以满足的代表需求数为阶段性目标，其上限为36；没有达到全部需求的中间结果只用于继续搜索，绝不会作为可用布局返回。

本方程使用等脉宽二进制组，不是任意不等脉宽的 \(A_Su=s e_k\)。同组同步开启和关闭时，在理想等推力、无阀门延迟的模型中，整个喷气区间都保持纯控制。组内每台按同一比例缩短脉宽不会破坏这一性质。

标况共有2047个非空偶数组；某台故障后仍有1023个不含故障机的非空偶数组。标况12个需求加上12种单故障各12个需求，总计156项。该计数是完整的编号组合目录，但不意味着已经逐一证明了连续参数空间中所有拓扑的可行或不可行。

## 4. 如何减少重复而不漏掉物理解

只使用可以验证的物理等价变换：

1. 三个模块具有相同边界，可以按模块的 \(y\) 值排序，去掉模块重编号造成的重复。
2. 同时对所有模块执行四列置换 \([2,1,4,3]\)，六维矩阵只发生行符号变化 \(\operatorname{diag}(1,-1,-1,1,-1,-1)\)。
3. 同时对所有模块执行 \([3,4,1,2]\)，行符号变化为 \(\operatorname{diag}(-1,1,1,1,-1,-1)\)。

由于每个轴的正负方向都检查，联合求解模型只需要检查故障1、5、9这三个代表，即可覆盖12种单故障。标况可直接使用任意单故障下的健康组，因而也自动具备相应能力。最终MATLAB仍逐一复核全部156项，不仅检查这三个代表。

**不能随意独立翻转某个位置变量或方向变量的符号再当作等价类。**例如改变 \(y\) 而不相应变换方向，会改变 \(M_x=y d_z-z d_y\)，甚至把原本为0的力矩变为非零。因此本版删除了之前的独立符号合并。

## 5. 首个可行解的实际搜索流程

默认 `solver="hybrid"`，顺序执行以下过程：

1. **先回读历史高覆盖候选。**读取项目中的已保存布局和最近12份搜索记录，按当前物理方程重新检查覆盖数，优先保留高覆盖起点。旧版五变量布局通过实际位置和方向转换，不能直接当成十二变量。显式指定的初值和恢复文件仍优先。
2. **固定组局部配平。**每项选当前最近组，用 `lsqnonlin` 每段最多8次迭代，再重新选组。单初值最多120次名义迭代。内外层现在保留相同的需求重复权重。历史最高覆盖候选独立保留，不能被低残差、低覆盖候选覆盖掉。
3. **固定方向，联合求位置和主备组。**对历史方向和保留精确力平衡关系的方向候选，先检查健康偶数组的纯力条件。若某个力方向根本没有健康组，无论怎样移动安装位置都不能修复，立即跳过。随后六个位置变量与组选择联合求解；方向固定后力矩是位置的仿射函数，组选择用有界线性约束表达。最小安装间距为0时是混合整数线性模型；非零间距时保留相应二次约束。
4. **持续记录阶段覆盖数。**该阶段先最大化满足的代表需求数，不最大化控制能力。对得到的几何重新枚举开关集合，计算实际156项覆盖并反馈软件。全部满足后立即停止；部分满足的几何作为下一阶段起点。
5. **自由方向联合搜索。**剩余预算中继续求完整连续几何和偶数组。完整方位角范围下用共享系数 `c,p,q,h,g,k`，只保留单位方向及力臂关系的12条物理非线性等式，二进制乘积用等价线性不等式表示；不再为每个工况重复展开三角表达式。用户限制方位角范围时，保留原三角模型以严格遵守范围。历史候选和固定方向阶段候选以部分初始解传入。
6. **独立物理复核。**重新构造位置、单位方向和力矩，复核安装边界及全部156项，不以优化器的覆盖目标值代替这一检查。
7. **实际调用器复核。**检查156项实际选择的健康偶数瞬时纯组，不允许冲量裕度降级，并检查实际组能力不是数值零。这里暂时去掉最小脉宽，只验证调用结构，不代替闭环性能测试。
8. **通过即停止并保存布局。**不继续提高控制能力。未通过完整复核的候选，只保存为搜索记录。

固定方向候选包括历史方向、三角/镜像方向族以及整数球面方向采样。这是搜索加速路径，不是全部解析拓扑库；没有找到解时仍不能据此判定整个连续空间无解。自由方向联合模型保留原来的连续构型空间。

选组时还排除一种确定不可能的情况：如果该组合在每个模块上的目标行符号系数都为0，那么无论怎样调整几何参数，其目标轴分量都恒为0。这样的组合不可能满足正的能力门槛，不应因为其他分量也为0而被局部搜索选中。此筛除不改变可行域，完整物理复核仍使用全部偶数组。

取消能力提升主要避免找到解后的继续计算，并不能保证更快找到第一套解。固定组内层配平同样是局部启发式，可能停滞。搜索超时不是无解证明。

## 6. 参数设置与复用失败候选

软件默认设置：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| 搜索目标 | 首个可行布局 | 不是能力最大化 |
| 初值数量 | 16 | 本地阶段最多尝试的起点数量 |
| 总搜索时限 | 600秒 | 10分钟搜索预算，不是保证完成时间 |
| 本地阶段时限 | 60秒 | 混合模式下取总时限与60秒的较小者 |
| 固定组内层迭代 | 8次 | 每段结束后才重新选组 |
| 单初值总迭代预算 | 120次 | 不随总时限自动增长 |
| 非零能力判据 | 1e-5 | 界面只读，用于排除数值零，不是任务能力要求 |
| 纯控制容差 | 1e-9 | 不放宽纯控制要求 |
| 首轮随机种子 | 18 | 同一次软件会话再次搜索时加1 |
| 单个固定方向方案时限 | 8秒 | 快速尝试多种方向方案 |
| 固定方向阶段预算比例 | 0.85 | 占进入联合阶段时剩余预算的比例 |

本次按用户要求取消0.1的任务能力门槛。`1e-5`只用于数值上确认目标控制量不是零，不能据此声称找到的布局满足特定任务的力或力矩需求。零门槛仍被拒绝，因为完全不喷气也会满足零等式。独立复核、进程启动和保存会增加少量总耗时。

同一次软件会话中，再次点击搜索会读取上一轮搜索文件里的失败候选，并更换种子。更改安装范围时，超出新范围的恢复候选会被忽略；不会直接使用它们作为合格布局。

MATLAB调用示例：

```matlab
cfg = struct('solver',"hybrid",'start_count',16,'max_time',600, ...
    'local_max_time',60,'inner_iterations',8,'max_iterations',120, ...
    'min_axis_capacity',1e-5,'pure_tolerance',1e-9,'seed',18,'save_result',true);
result = Optim_Algorithm(Get_params(),cfg);
```

跨软件重启也会自动回读项目中的历史布局和近期候选，并以新的判据重算排序。指定其他路径时仍可使用 `cfg.resume_file`。回读的是几何起点，不是SCIP搜索树；不会把失败候选直接导入软件。旧脚本若显式传入 `min_axis_capacity=0.1`，仍会使用这个显式值；只研究非零可行性时应删掉旧值或改成上述数值判据。

`solver="native"` 将整个时限用于局部搜索；`solver="scip"` 直接联合求解，仅在有待精修候选时使用本地配平。初值和恢复文件不是对SCIP搜索空间的限制。

## 7. 失败诊断与结果字段

每轮生成同一基本名称的文件：

- **.mat**：完整配置、实际初值、外层搜索轨迹、最佳覆盖候选、最佳残差候选、具体缺失项、恢复起点、验证拒绝原因、求解器环境和状态。MATLAB结构名称为 `saved`。
- **.txt**：可直接阅读的中文诊断，含状态代码、阶段耗时、随机种子、候选参数、缺失故障轴、最近偶数组、耦合分量、能力缺口和完整异常堆栈。
- **.solver.log**：联合求解器产生的原始日志；没有运行联合求解器或没有输出时不生成。

失败文件以 `Optim_search_` 开头，不会自动导入布局。只有通过全部验证的结果使用 `Optim_data_`。软件输入校验等尚未进入优化器的异常，另存 `Optim_error_*.txt`。正常超时不弹异常错误框，但底部状态栏和结果摘要会说明结果；失败时当前布局保持不变。

状态代码：

| 状态 | 含义 |
|---|---|
| `feasible` | 首个候选通过全部物理及调用器复核 |
| `time_limit` | 搜索达到阶段或总预算，未找到合格布局 |
| `not_found` | 初值搜索结束，未找到合格布局 |
| `infeasible_for_capacity` | 求解器在数值容差下判定当前模型、边界及门槛不可行 |
| `candidate_rejected` | 候选未通过安装、纯组或调用器的独立检查 |
| `solver_stopped` | 联合求解器因其他终止原因退出，详见其状态 |
| `solver_error` / `error` | 求解环境或代码异常，详见错误标识和堆栈 |

重要字段：

- `search_goal="first_feasible"`、`global_certified=false`、`fval=NaN`：本阶段不输出控制能力最优性结论。SCIP常数目标的上下界即使都为0，也不是控制能力上下界。
- `best_coverage_candidate`：最佳覆盖候选的12变量、156项布尔检查、最近组选取、目标能力、非目标最大分量、严格纯组最大能力、安装违反量和边界违反量。
- `best_residual_candidate` / `diagnostic_x`：残差范数最低的候选，可能与最高覆盖候选不同。
- `diagnostic_missing`：仅列最高覆盖候选的缺失项。故障编号0表示标况；故障编号1至12表示相应推力器失效。这里的“无纯组”只针对这套候选，不能推广到整个连续空间。
- `trace`：外层候选评价的阶段、初值编号、换组轮数、耗时、覆盖数、残差范数和求解器退出码。`missing_frequency` 只是这些采样点的缺失计数，不是失败概率。
- `initial_points` / `resume_candidates` / `history_sources`：本轮实际初值、下一轮起点，以及自动回读的文件来源。
- `validation_rejections`：独立复核拒绝的候选，以及具体故障、带符号轴、调用器选择的组与状态。
- `solver_evidence`：终止原因、候选、节点数、环境版本、原始日志，以及每个固定方向方案的角度、状态和覆盖数；发生异常时含完整错误报告。

可行结果另有 `topology_map` 和 `axis_capacity_normalized`，尺寸13×12：第1行为标况，第f+1行为故障f；列顺序为-Fx、+Fx、-Fy、+Fy、-Fz、+Fz、-Mx、+Mx、-My、+My、-Mz、+Mz。能力只是对找到布局的测量，不是进一步优化的结果。`invocation_axis_capacity_normalized` 记录现有最简调用策略选中组的能力，可能与最大能力偶数组不同。

后续分析时首先查看TXT，涉及变量精度、恢复或复现实验时读取MAT；需要定位联合求解过程再查看SOLVER.LOG。没有完整可行解时，不把诊断候选的矩阵写入可导入布局字段。
